# FlowMesh acceptance corpus / sourced from the prior local FocusGate architecture

A MIDI event is a symbolic message describing note or controller data. MIDI is not an acoustic recording and MIDI event timings are not inherently model thinking speed.

A DAW edits time-addressed media. Tracks, clips and routing do not require replacing the sound engine when the selected visual facade changes.

The FocusGate M0.2 prototype recorded 56 consecutively numbered simulated ticks during facade switching, a staged capability promotion and rollback. This is a software continuity test, not a claim of real-time MIDI timing.

GHOSTFIELD remains a proposed independent MIDI service for Linux. Its port stability, Note On/Off and CC16 readback into REAPER need physical host verification.
