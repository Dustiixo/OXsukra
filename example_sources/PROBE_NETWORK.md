# FlowMesh example research notes: bounded scheduling hypotheses

An agent research probe should launch because it addresses a specific evidence gap, independent question or contradiction, not merely because a model produced interesting prose.

Budget allocation should account for observed evidence gain, user focus, cost and diminishing returns. Unverified model proposals must not be scored as evidence.

Dormant agent branches can be parked with their state retained. New relevant evidence may trigger a bounded reactivation, with loop limits to avoid expensive repeated work.

Two independent probes can converge on one exact source excerpt. Shared citations are traceable connections, not proof that their conclusions agree.

The primary goal remains addressable while its research branches grow and contract. Only one session state owner should commit the event ledger.
