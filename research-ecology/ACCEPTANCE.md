# M0.1 acceptance and limits — 2026-10-28

## Proven in isolated local tests

- Local owner database; event hash chain; tamper detection.
- 40-minute future study proposal stored as `NOT_REQUESTED` (not a live Slotline booking).
- Study session -> source distillation -> research tick -> human hypothesis -> recall/recap.
- Source text parser excludes script content; classification/digest bounded.
- Basic public HTTPS host restrictions and local/private DNS rejection (not a production security audit).
- Companion responds to study events and honours a ten-minute silence window; has no UNDERBYTE state.
- Test command: `python -m unittest discover -s tests -v`

## Not proven

- Windows native UI startup and Tk availability on user's machine.
- Any actual external webpage fetch; no live internet attempt was run in acceptance.
- Source scientific accuracy; text digest is deterministic extraction, not LLM or truth verification.
- Slotline schedule modification, live calendar sync or weekly autonomous bot.
- PARALLAX/Jev authenticated browser capture; Odysseus reasoning; WRAP/Thought Spine/EUREKA imports; Academy awarded credentials.
- Managed one-time Windows installation/auto-update/rollback; Linux/Windows portability beyond Python module tests.

## Next stage / prerequisites

G0.2: host-probe Python/Tk and full GUI click acceptance; adapter validators against *actual* installed Slotline/Linking Fabric schemas, signed contract revision, explicit consent and source-preserving provenance; then deterministic weekly planning proposals; subsequently provider-approved AI distillation. Keep independently verified receipts separate from self-attested learning.
