# OXsukra

**Local-first software, independent programs, one inspectable connection fabric.**

OXsukra is the umbrella for IXO and a family of creative, technical and
experimental programs. IXO is the native human–computer operating/workflow
foundation inside it—not a renamed website, and not the sole owner of every
application's memory or data.

This GitHub repository is the **public architecture and project index**.
It is intentionally **not** a dump of private IXO source, personal captures,
model files, device backups or collaborators' code.

## Architecture, not a giant shared state dump

- **IXO:** a native shell, project/spine state, permission/approval ownership.
- **Thought Spine, WRAP, EUREKA, Opris, DÉJÀ:** continuity and revision-aware
  memory interfaces with separate ownership and evidence.
- **Foundry, Packbot, Witness, Release Controller:** construction and
  verification, with test/rollback gates.
- **SpatialDoor, ECHOFOLD.VME, ORBITAL, Mutation Board:** visualization,
  simulation, and source-linked editing surfaces.
- **VELA, GHOSTFIELD, TESSERA:** independent music/audio creation and transport.
- **GREMLIN, Underbyte, TimePair:** offline-capable mobile and time interfaces.
- **PARALLAX, StayScraping, Lead Radar:** bounded web research and data intake.
- **STRAY, Trainer, Glimmer, byte curriculum:** independently evaluated
  model/research experiments, not an unchecked autonomous authority.

See [the project ownership map](docs/PROJECT_MAP.md) for further identities.
The private intake register currently tracks **80 named concepts/subsystems**
across the broader ecosphere. Being listed does **not** mean a working program
or a GitHub repository exists.

## What is proven?

On 2026-11-20, source archives independently reran **5 M0 repository-contract
tests**, **152 archived IXO foundation tests**, and **18 original Cubix tests**
in a Linux workspace. These are three **different codebases/scopes** and
cannot be added up into an integrated-platform pass.

The original installed ASUS native IXO, Windows GUI, Android lifecycle, real
3D rendering, protected agent execution and cross-device recovery have **not**
been certified by these checks. See [evidence and release requirements](docs/RELEASE_EVIDENCE.md).

Work moves from verified source → one native owner action → independent proof
→ reviewable release. Every project keeps its identity and history.
