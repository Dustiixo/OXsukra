# Capsule Board (R0)

This is a public **candidate review board**, not the source tree of the underlying programs.

The 27 capsule IDs are neutral pointers. Each is **UNVERIFIED** until an independent reviewer provides reproducible source/test evidence. Do not treat this as deployment status.

## How to contribute

Choose an ID from `capsules.json`. Submit a reviewable finding with reproducible steps, environment, expected and actual outputs, source commit or artifact hash when you are authorized to access it, and PASS / FAIL / BLOCKED. No original source, account credentials, or private project names should be posted here.

## Privacy and ownership

An alias is not anonymization: this branch is under a publicly visible GitHub account. Project/source mappings are kept in a separate private continuity archive. Collaborators need explicit access to relevant code; do not infer project ownership or permission from an alias. Do not combine systems or alter other contributors' repositories without authorization.

## Rhythm

Recover source → bounded probe → tiny reversible change → test locally → cross-system contract check → receipt → review → next ripple. Keep historical releases and test failures. This branch does not authorize unattended writes to protected branches.
