# Sharing without publishing the private map

Public side is `public/` only; names `C001` ... are neutral markers, NOT secrecy. The repository owner and commit activity remain visible. A collaborator can read a capsule's evidence gaps and submit findings against an alias. They require an explicitly shared private mapping to work on a real project; avoid putting private repo links or internal project names in public issues/PRs.

**Safe pattern**: public code/contract where cleared; private repository with per-collaborator access for actual source; review PRs for contributions; immutable signed/hashed releases for delivery. Public repository aliases cannot provide access control. Maintain LICENSE attribution and historical original authors.

Current account has existing GitHub repositories with write permission, but the connector does not expose a create-repository action. This pack is ready for per-capsule repositories, but this run cannot honestly claim to have created those repositories.
