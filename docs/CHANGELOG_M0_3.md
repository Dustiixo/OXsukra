# M0.3 Visual Candidate · Changelog

- Introduced `spatial_lab/` experimental browser UI, independent of old Tkinter desktop and prior M0.2 Visual Lab.
- Replaced flat boxed node graph with perspective 3D orbital research space, depth parallax, and time-bound event visual effects.
- Added actual receipt-sequence playback with branch status, shared-evidence lines, proof text, SHA-256 field, and explanatory record panel.
- Added mouse orbit, wheel zoom, node selection/focus, camera reset, keyboard stepping, pause/play, local JSON import, mobile evidence drawer.
- Added opt-in loopback-only, token-protected read-only bridge that verifies FlowMesh ledger on each request and refuses invalid sessions; no mutation routes.
- Kept original M0.1.1 UTF-8 guard, FlowMesh engine and M0.2 exporter code unchanged.
- Added browser, bridge, and security regression tests. See `SPATIAL_CHAMBER_TEST_REPORT.md`.
