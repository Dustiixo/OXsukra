# OXsukra foundation — cognitive mesh coordination note
**Date:** 2026-10-28. **Status:** Documentation-only proposal; no foundation source, installed service or release is added by this PR.

## Intended role
This repository is the umbrella/foundation identity for OXsukra, not a bucket that absorbs independent application owners. A central LLM can interpret cross-system goals, but deterministic services must remain the kernel-level authority for queueing, time, permissions and proof. Each program keeps a local cognitive context and source-owned data. Three program states are PASSIVE (lightweight monitor), ACTIVE (bounded reasoning/work) and RELAY (persist a handoff, then return to passive).
