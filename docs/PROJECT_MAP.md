# OXsukra project map — 2026-11-20

This document is the **public-facing projection** of a larger private owner
inventory. It names boundaries and current paths without exposing personal
data, private notes, partner source, model weights, or unlicensed assets.

## The genuine source position

1. Private IXO M0 Git bundle: original two-commit history recovered locally.
   This is a **source-first baseline**, not proof that every newer subsystem
   was merged into the installed product.
2. IXO archived engineering v0.4.1: executable Python implementation with
   separate local unit-test proof. It is not automatically the latest IXO.
3. Cubix M0.1: three-commit source history recovered from the original bundle.
   Its public repository currently contains a checkpoint, not the code.
4. Foundry November 18 review branches: native convergence, Glimmer/audio
   forensics and byte cognition candidates. Historical test reports exist;
   do not silently fold them into the private host installation.
5. Newer sketches and UI images: meaningful requirements and design taste,
   **not** production software or released native integrations.

## Release routing

Each project receives its own README, source map, honest current state,
versioned interfaces, acceptance instructions, test results, known failures,
and privacy/licence review **when its actual source is ready**. Related modules
may stay inside their true owner repository until they warrant independence.

The following new repositories are potential **private** destinations after
source and owner checks: IXO, VELA, GREMLIN, Thought Spine, ORBITAL,
ECHOFOLD, PARALLAX, TimePair, Underbyte, Homebrew Editor, Lead Radar and
Mutation Board. None of these names in this paragraph asserts creation.

Collaborator-owned APC/Odin and Syntra/Astra-Lang work are external interfaces,
not repositories to mirror or represent as OXsukra-owned source.
