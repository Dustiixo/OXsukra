# Rollback / M0.4

1. Close the browser window opened by `START_DUAL_SURFACE.cmd`.
2. Remove only the extracted `IXO_FlowMesh_Dual_Surface_GPU_M0_4_Candidate` folder.
3. To run the preceding candidate, reopen the independent M0.3 ZIP and its `START_SPATIAL_CHAMBER.cmd`.
4. To return to the immutable baseline, reopen the original `IXO_FlowMesh_M0_1.zip` separately.

Never remove or overwrite research workspaces, private trace files, or another project's repository. The GPU viewer is read-only and does not alter existing FlowMesh state.
