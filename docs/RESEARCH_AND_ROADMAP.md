# BYTE × RCLL × SELF | Unbounded research agenda, bounded promotions

## Thesis

Keep original bytes as the irreplaceable source of truth. Allow overlapping **separate, synchronized representations**, not destructive conversions: learned byte patches, symbolic relationships, signal/audio representation, geometry, Self live objects, and program edits. Candidate insights must remain linked to exact byte ranges and evidence. Language models and visualizers are *views*, not owners of truth.

## Four research lanes

A. **Byte-native intelligence:** independently reproduce Meta BLT with pinned upstream refs, weights, license review, local GPU/memory budget, and learned next-byte entropy patches. Compare fixed-size chunks, the shipped heuristic and actual BLT with equal compute budget on the same inputs. Measure reconstruction, boundary sensitivity, latency and memory. Evaluate 2026 Fast BLT work only if code is available and licenses permit.

B. **Native Self world:** run actual `russellallen/self` VM/world/Morphic, not a clone. Load prototype modules in an independent transporter tree, inspect mirrors/outliners, edit slots, prove module file-out and restart consistency. Transport only typed data through a local broker; no executable expression accepted from web requests. All VM/World resources are external dependencies, never silently replaced.

C. **Your representation system:** extend the existing RCLL/COLOCRYPT/PRINT and 1,000 micro-splice fabric; introduce typed relationships, time anchors, graph edges, audio events, visual depth, uncertainty, and provenance. Add entropy, novelty, conditional byte predictors and collision tests. Cross-modality mappings must distinguish invented sonification from measured audio and from AI-recognized meaning.

D. **IXO/VELA application:** connect a single source object to ORBITAL/Thought Spine, VELA listening, ECHOFOLD visual surfaces and the Opris continuity ledger with *read-only* adapters first. VELA's uninterrupted audio transport is separate from the slower listen-decide-generate loop. Later, generate a reversible candidate musical change and apply on a timed boundary only after gate approval.

## Milestone ladder

- **G0 (this release):** source bytes roundtrip exactly, patch offsets cover original, 1,000 addresses, native object source written, OBJ/WAV projections, independent tests.
- **G1 (priority):** native Self parsing + real Morphic inspect/edit + read-only receipt, validated against exact source identity.
- **G2:** first measured Meta BLT encoder with reproducible environment; prove distinctions from heuristic and report actual compute costs.
- **G3:** byte/object alignment across prompt, audio and code with source traceability, uncertainty and explicit unverifiable gaps.
- **G4:** independent adapters to IXO and VELA on synthetic data, real source object IDs, event queues and deterministic rollback.
- **G5:** agent-assisted experimental mutation in isolated disposable forks, independent observer, stable comparison tasks, no promotion without human-owned gate.
- **G6+ open:** generalize to executable multi-perspective object worlds, time-varying audiovisual relationships, representations learned from causal outcomes, persistent research notebooks, federated models, spatial operating surfaces. Propose bigger experiments when evidence supports them; no preset upper limit on research scope.

## Anti-stagnation rules

Every iteration must pick **one hard failure or measurable capability**, not cosmetic version bumps; change implementation or write a falsifiable rejection report; run full tests; preserve original source; record reproducible commands, exact results and stop conditions; keep old rejected variants. Coordinate with the hourly OX Ripple and VELA tracks without overwriting their lineage. Never claim integration from documentation alone.

## Current experiment benchmarks

1. Deterministic identity despite changed file extension/name.
2. Random, low-entropy, sparse, invalid and malicious binary inputs.
3. Full byte coverage and exact roundtrip (not lossy WAV/geometry reconstruction).
4. Same spatial addresses across byte and audio ledgers, while keeping their meanings distinct.
5. Concurrency conflict rejection, ledger tamper detection, no unauthorized code execution.
6. Real Self outliner receives and returns a verified slot change (not yet achieved).
7. Learned BLT produces measured improvement over simple baseline on an agreed task (not yet achieved).
